# CPA 认证文件管理中心

CLI Proxy API 认证文件的 Web 管理面板，提供可视化的账号管理、自动巡检和状态监控。

## 功能

- **账号管理** — 查看所有认证文件状态，一键启用/禁用
- **自动管理** — 智能维持目标活跃账号数，自动替换异常账号
- **定时巡检** — 可配置间隔的自动巡检，支持页面刷新后恢复
- **操作日志** — 实时记录所有操作，支持持久化到后端
- **优先级管理** — 为账号设置优先级标签，影响自动管理选择顺序
- **记住密码** — 登录凭据加密存储于浏览器，支持自动登录
- **二次确认** — 所有操作和配置修改均有确认弹窗，防止误操作

## 架构

```
浏览器 (dashboard.html)
  │
  ├── /auth/verify     → 登录验证（实际连接上游测试）
  ├── /api/*           → 代理上游 CPA 管理 API
  ├── /local/config    → 面板配置持久化
  ├── /local/priority  → 优先级数据持久化
  └── /local/logs      → 巡检日志持久化
  │
cpa_server.mjs (Node.js 后端)
  │
  └── 上游 CPA 管理 API (/v0/management/*)
```

- **后端**（`cpa_server.mjs`）负责代理上游 API、持久化本地数据，不暴露管理密钥
- **前端**（`dashboard.html`）单文件 SPA，包含所有 UI 和交互逻辑
- **凭据**由前端登录时提交，后端内存持有，无硬编码

## 快速开始

```bash
# 启动（默认端口 3456）
node cpa_server.mjs

# 自定义端口
PORT=8080 node cpa_server.mjs

# 使用 PM2 部署
pm2 start cpa_server.mjs --name cpa-management
```

启动后在浏览器打开 `http://localhost:3456`，输入上游 API 地址和管理密钥即可登录。

## 配置说明

### 服务端配置

| 文件 | 说明 |
|------|------|
| `cpa_config.mjs` | 管理 API 路径前缀 |

### 面板配置（通过 UI 修改，持久化到后端）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| 目标数 | 5 | 自动维持的活跃账号数量 |
| 超时 | 30s | API 请求超时时间 |
| 巡检间隔 | 180s | 定时巡检执行间隔 |

### 持久化文件

| 文件 | 说明 |
|------|------|
| `cpa_dashboard_config.json` | 面板配置 + 巡检状态 |
| `cpa_priority.json` | 账号优先级数据 |
| `cpa_logs.json` | 操作日志（最多 500 条） |

## 安全

- 管理密钥不硬编码在服务端，登录时由前端提交
- 后端内存持有凭据，重启后需重新登录（前端记住密码功能自动处理）
- 前端"记住密码"使用 XOR + Base64 加密存储于 `localStorage`，密钥绑定域名和浏览器
- 所有 `/api/*` 和 `/local/*` 接口需要 Bearer Token 鉴权
- 所有操作和配置修改均有二次确认弹窗
